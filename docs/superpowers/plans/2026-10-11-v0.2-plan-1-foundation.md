# v0.2 Plan 1: Workspace foundation, protocol and scheduler

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the Rust workspace with strict quality gates, the `ocm-proto` crate (node to coordinator protocol v2 with Ed25519 frame signing) and the `ocm-sched` crate (pure load manager), so every later v0.2 stream builds on stable, tested interfaces.

**Architecture:** One Cargo workspace at the repo root. `ocm-proto` and `ocm-sched` are pure crates: no I/O, no clocks, no global state, so they are deterministic, fast to test and fuzzable. The v0.1 Rust agent at `crates/ocm-node` is excluded from the workspace until Plan 4 replaces it.

**Tech Stack:** Rust 1.99 (edition 2024, MSRV 1.85), serde, serde_json, ed25519-dalek 3, getrandom 0.3; dev: proptest; CI: GitHub Actions, cargo-deny, cargo-fuzz (nightly).

**Spec:** `docs/superpowers/specs/2026-10-11-v0.2-native-core-design.md`

## Global Constraints

- License Apache-2.0; every crate sets `license.workspace = true`.
- Edition 2024; `rust-version = "1.85"`; one workspace version `0.2.0-alpha.0`.
- `unsafe_code = "forbid"` in every crate.
- `cargo fmt --check` and `cargo clippy --workspace --all-targets -- -D warnings` (clippy pedantic enabled) must pass.
- Every dependency is listed with a justification in `docs/DEPENDENCIES.md`; default features disabled where the crate allows it.
- Pure crates (`ocm-proto`, `ocm-sched`) must not depend on tokio, std::time::SystemTime, threads, files or sockets.
- Protocol: JSON frames with `v: 2`; unknown fields rejected; maximum frame size 1 MiB (1,048,576 bytes).
- Result frames (`job_completed`, `job_failed`) are signed with Ed25519 over the canonical bytes of the frame with `sig` omitted.
- Errors returned by decoding never contain any substring of the input payload (prompts must not leak into logs).
- Scheduler decision budget: under 50 microseconds per decision at 10,000 candidate nodes (release build).
- Commit subjects use Conventional Commits (`feat:`, `fix:`, `test:`, `ci:`, `docs:`, `chore:`), each ending with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Decode errors must not echo payload text: a frame whose field holds `SECRET-PROMPT` must produce an error whose `Display` lacks that string (Task 1).
2. Deeply nested JSON (10,000 levels) must return `ProtoError::Malformed`, never overflow the stack or panic (Task 1).
3. NaN, zero, negative or infinite measured throughput must fall back to the prior and never yield a NaN score (Task 5).
4. A candidate slice with duplicate node ids, or a single eligible node among thousands, must still return a valid eligible id (Task 6).
5. A clock that moves backwards (`now_ms` earlier than the breaker's open time) must not panic or underflow; the breaker stays open (Task 7).

`crates/ocm-proto/src/frame.rs`:
```rust
//! The frame envelope shared by every message.

use std::fmt;

use serde::{Deserialize, Serialize};

use crate::Body;

/// Protocol version carried by every frame.
pub const PROTOCOL_VERSION: u16 = 2;

/// Largest accepted encoded frame in bytes (1 MiB).
pub const MAX_FRAME_BYTES: usize = 1 << 20;

/// One protocol message.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct Frame {
    /// Protocol version; must equal [`PROTOCOL_VERSION`].
    pub v: u16,
    /// Sender-unique, increasing frame id.
    pub id: u64,
    /// Sender wall-clock time in Unix milliseconds.
    pub ts: u64,
    /// The message payload.
    pub body: Body,
    /// Lowercase hex Ed25519 signature over the canonical bytes of this frame with `sig` omitted.
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub sig: Option<String>,
}

/// Why a frame was rejected. Messages never include payload content.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum ProtoError {
    /// The encoded frame exceeds [`MAX_FRAME_BYTES`]; carries the received length.
    TooLarge(usize),
    /// The bytes are not a valid v2 frame; carries a content-free description.
    Malformed(String),
    /// The frame declares an unsupported protocol version.
    Version(u16),
    /// A required signature is absent.
    MissingSignature,
    /// The signature or key is invalid.
    BadSignature,
}

impl fmt::Display for ProtoError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            Self::TooLarge(n) => write!(f, "frame of {n} bytes exceeds {MAX_FRAME_BYTES}"),
            Self::Malformed(why) => write!(f, "malformed frame: {why}"),
            Self::Version(v) => write!(f, "unsupported protocol version {v}; upgrade to version {PROTOCOL_VERSION}"),
            Self::MissingSignature => f.write_str("missing signature"),
            Self::BadSignature => f.write_str("invalid signature"),
        }
    }
}

impl std::error::Error for ProtoError {}

impl Frame {
    /// A new unsigned frame at the current protocol version.
    pub fn new(id: u64, ts: u64, body: Body) -> Self {
        Self { v: PROTOCOL_VERSION, id, ts, body, sig: None }
    }

    /// Canonical encoding: struct fields serialize in declaration order, so equal frames encode equally.
    ///
    /// # Panics
    /// Never: every field type serializes infallibly.
    pub fn encode(&self) -> Vec<u8> {
        serde_json::to_vec(self).expect("frame fields always serialize")
    }

    /// Decode and validate one frame.
    ///
    /// # Errors
    /// Returns [`ProtoError`] for oversized, malformed or wrong-version frames.
    pub fn decode(bytes: &[u8]) -> Result<Self, ProtoError> {
        if bytes.len() > MAX_FRAME_BYTES {
            return Err(ProtoError::TooLarge(bytes.len()));
        }
        match serde_json::from_slice::<Frame>(bytes) {
            Ok(f) if f.v == PROTOCOL_VERSION => Ok(f),
            Ok(f) => Err(ProtoError::Version(f.v)),
            Err(e) => Err(legacy_version(bytes).map_or_else(|| ProtoError::Malformed(describe(&e)), ProtoError::Version)),
        }
    }
}

/// A content-free description of a JSON error: its category and position only.
fn describe(e: &serde_json::Error) -> String {
    let kind = match e.classify() {
        serde_json::error::Category::Io => "io",
        serde_json::error::Category::Syntax => "syntax",
        serde_json::error::Category::Data => "invalid structure",
        serde_json::error::Category::Eof => "unexpected end",
    };
    format!("{kind} at line {} column {}", e.line(), e.column())
}

/// v1 frames are flat objects with `protocol_version`; report their version so callers can say "upgrade".
fn legacy_version(bytes: &[u8]) -> Option<u16> {
    let v: serde_json::Value = serde_json::from_slice(bytes).ok()?;
    u16::try_from(v.get("protocol_version")?.as_u64()?).ok().filter(|n| *n != PROTOCOL_VERSION)
}
```

//! Message bodies exchanged between nodes and a coordinator.

use serde::{Deserialize, Serialize};

/// A frame payload, tagged by `type` with its fields under `data`.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(tag = "type", content = "data", rename_all = "snake_case", deny_unknown_fields)]
pub enum Body {
    /// Node to coordinator, first frame: enroll with a token or authenticate with a node id.
    Hello(Hello),
    /// Coordinator to node: accepted; carries the assigned node id.
    Welcome(Welcome),
    /// Node to coordinator: periodic liveness and resource snapshot.
    Heartbeat(Heartbeat),
    /// Node to coordinator: refreshed capabilities after a model change.
    Capabilities(Capabilities),
    /// Coordinator to node: run a job.
    JobStart(JobStart),
    /// Coordinator to node: stop a job.
    JobCancel(JobRef),
    /// Node to coordinator: the runtime accepted the job.
    JobStarted(JobRef),
    /// Node to coordinator: one streamed chunk of output.
    JobToken(JobToken),
    /// Node to coordinator: final statistics. Must be signed.
    JobCompleted(JobCompleted),
    /// Node to coordinator: the job ended without a result. Must be signed.
    JobFailed(JobFailed),
    /// Either direction: a refusal with a stable code and a content-free message.
    Error(ErrorMsg),
    /// Either direction: application-level liveness probe.
    Ping,
    /// Reply to [`Body::Ping`].
    Pong,
}

impl Body {
    /// Whether frames carrying this body must be signed by the node key.
    pub fn requires_signature(&self) -> bool {
        matches!(self, Self::JobCompleted(_) | Self::JobFailed(_))
    }
}

/// First node frame.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct Hello {
    /// Single-use enrollment token, for a first connection.
    pub enrollment_token: Option<String>,
    /// Previously assigned node id, for reconnection.
    pub node_id: Option<String>,
    /// Lowercase hex Ed25519 public key (32 bytes).
    pub public_key: String,
    /// What the node offers.
    pub caps: Capabilities,
}

/// Enrollment or authentication accepted.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct Welcome {
    /// The node's id on this coordinator.
    pub node_id: String,
}

/// Liveness and resource snapshot.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct Heartbeat {
    /// Whether the node's runtimes answered their health check.
    pub healthy: bool,
    /// Free memory in bytes, when known.
    pub mem_free: Option<u64>,
    /// Digests of models currently loaded in memory.
    pub loaded: Vec<String>,
}

/// Hardware and models a node offers.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct Capabilities {
    /// Display name chosen by the owner.
    pub name: String,
    /// Operating system and version.
    pub platform: String,
    /// CPU architecture.
    pub arch: String,
    /// CPU model, when known.
    pub cpu: Option<String>,
    /// Logical CPU count, when known.
    pub cores: Option<u16>,
    /// Total memory in bytes, when known.
    pub mem_total: Option<u64>,
    /// Detected accelerators, each labelled with its detection source.
    pub accelerators: Vec<Accelerator>,
    /// Owner-approved models.
    pub models: Vec<ModelInfo>,
    /// Concurrent job slots the owner allows.
    pub slots: u16,
}

/// A detected GPU or neural accelerator.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct Accelerator {
    /// Device name.
    pub name: String,
    /// Dedicated memory in bytes, when known.
    pub mem: Option<u64>,
    /// How it was detected.
    pub source: String,
}

/// One model a node serves.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct ModelInfo {
    /// Model id as the runtime names it.

//! Node identity and result-frame signatures.

use ed25519_dalek::{Signature, Signer, SigningKey, Verifier, VerifyingKey};

use crate::{Frame, ProtoError};

/// A node's Ed25519 identity. The secret never leaves the node.
pub struct NodeKey(SigningKey);

impl NodeKey {
    /// Generate a key from operating-system randomness.
    ///
    /// # Errors
    /// Returns the OS error when randomness is unavailable.
    pub fn generate() -> Result<Self, getrandom::Error> {
        let mut secret = [0u8; 32];
        getrandom::fill(&mut secret)?;
        Ok(Self::from_secret(secret))
    }

    /// Restore a key from its 32-byte secret.
    pub fn from_secret(secret: [u8; 32]) -> Self {
        Self(SigningKey::from_bytes(&secret))
    }

    /// The 32-byte secret, for storage with owner-only file permissions.
    pub fn secret(&self) -> [u8; 32] {
        self.0.to_bytes()
    }

    /// Lowercase hex public key.
    pub fn public_hex(&self) -> String {
        to_hex(self.0.verifying_key().as_bytes())
    }

    /// Sign the canonical bytes of `frame` with `sig` omitted, and set `sig`.
    pub fn sign(&self, frame: &mut Frame) {
        frame.sig = None;
        let sig = self.0.sign(&frame.encode());
        frame.sig = Some(to_hex(&sig.to_bytes()));
    }
}

/// Verify a frame's signature against a lowercase hex public key.
///
/// # Errors
/// [`ProtoError::MissingSignature`] when unsigned; [`ProtoError::BadSignature`] for any invalid key or signature.
pub fn verify(frame: &Frame, public_hex: &str) -> Result<(), ProtoError> {
    let sig_hex = frame.sig.as_deref().ok_or(ProtoError::MissingSignature)?;
    let key = from_hex::<32>(public_hex)
        .and_then(|b| VerifyingKey::from_bytes(&b).ok())
        .ok_or(ProtoError::BadSignature)?;
    let sig = from_hex::<64>(sig_hex).map(|b| Signature::from_bytes(&b)).ok_or(ProtoError::BadSignature)?;
    let mut unsigned = frame.clone();
    unsigned.sig = None;
    key.verify(&unsigned.encode(), &sig).map_err(|_| ProtoError::BadSignature)
}

fn to_hex(bytes: &[u8]) -> String {
    const DIGITS: &[u8; 16] = b"0123456789abcdef";
    let mut out = String::with_capacity(bytes.len() * 2);
    for b in bytes {
        out.push(char::from(DIGITS[usize::from(b >> 4)]));
        out.push(char::from(DIGITS[usize::from(b & 0x0f)]));
    }
    out
}

fn from_hex<const N: usize>(s: &str) -> Option<[u8; N]> {
    let raw = s.as_bytes();
    if raw.len() != N * 2 {
        return None;
    }
    let nibble = |c: u8| match c {
        b'0'..=b'9' => Some(c - b'0'),
        b'a'..=b'f' => Some(c - b'a' + 10),
        _ => None,
    };
    let mut out = [0u8; N];
    for (i, pair) in raw.chunks_exact(2).enumerate() {
        out[i] = (nibble(pair[0])? << 4) | nibble(pair[1])?;
    }
    Some(out)
}

//! SplitMix64: tiny, fast, seedable; good enough for load balancing, not for cryptography.

/// Deterministic pseudo-random generator.
#[derive(Debug, Clone)]
pub struct Rng(u64);

impl Rng {
    /// A generator from a seed; equal seeds give equal sequences.
    pub fn new(seed: u64) -> Self {
        Self(seed)
    }

    /// Next 64 random bits.
    pub fn next_u64(&mut self) -> u64 {
        self.0 = self.0.wrapping_add(0x9E37_79B9_7F4A_7C15);
        let mut z = self.0;
        z = (z ^ (z >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
        z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
        z ^ (z >> 31)
    }

    /// Uniform index in `0..n` (Lemire's multiply-shift; unbiased enough for scheduling).
    ///
    /// # Panics
    /// Panics if `n` is zero.
    pub fn below(&mut self, n: usize) -> usize {
        assert!(n > 0, "below(0)");
        let wide = u128::from(self.next_u64()) * (n as u128);
        usize::try_from(wide >> 64).expect("result is below n, which fits in usize")
    }
}

//! Exponentially weighted moving average of measured performance.

/// Moving average; `None` until the first valid sample.
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Ewma {
    value: Option<f64>,
    alpha: f64,
}

impl Ewma {
    /// `alpha` in (0, 1]: weight of the newest sample.
    pub const fn new(alpha: f64) -> Self {
        Self { value: None, alpha }
    }

    /// Add a sample; non-finite and negative samples are ignored.
    pub fn observe(&mut self, x: f64) {
        if !x.is_finite() || x < 0.0 {
            return;
        }
        self.value = Some(self.value.map_or(x, |v| v + self.alpha * (x - v)));
    }

    /// Current average.
    pub fn get(&self) -> Option<f64> {
        self.value
    }
}

    pub reputation_floor: f64,

    pub cold_load_ms: f64,
    /// Throughput assumed for nodes without measurements.
    pub prior_tps: f64,
    /// Time to first token assumed for nodes without measurements.
    pub prior_ttft_ms: f64,
}

impl Default for Policy {
    fn default() -> Self {
        Self { reputation_floor: 0.5, cold_load_ms: 1_500.0, prior_tps: 20.0, prior_ttft_ms: 500.0 }
    }
}

/// A request to place.
#[derive(Debug, Clone, Copy)]
pub struct Request<'a> {
    /// Required model digest.
    pub digest: &'a str,
    /// Expected output tokens (the request's limit).
    pub est_tokens: u64,
    /// Nodes that must not be chosen (for example, after a failed attempt).
    pub exclude: &'a [NodeId],
    /// Only this node may be chosen.
    pub pin: Option<NodeId>,
}

/// The model stat when `node` may take `req`, else `None`.
pub fn eligible<'n>(node: &'n NodeSnapshot, req: &Request<'_>, policy: &Policy) -> Option<&'n ModelStat> {
    let open = node.online
        && node.sharing
        && !node.breaker_open
        && node.reputation >= policy.reputation_floor
        && node.active < node.slots
        && !req.exclude.contains(&node.id)
        && req.pin.is_none_or(|p| p == node.id);
    if !open {
        return None;
    }
    node.models.iter().find(|m| m.digest == req.digest)
}

/// Expected milliseconds until `req` would finish on `node`.
#[allow(clippy::cast_precision_loss)] // token counts far below 2^52
pub fn expected_ms(node: &NodeSnapshot, stat: &ModelStat, req: &Request<'_>, policy: &Policy) -> f64 {
    let tps = stat.tps.get().filter(|v| *v > 0.0).unwrap_or(policy.prior_tps);
    let ttft = stat.ttft_ms.get().unwrap_or(policy.prior_ttft_ms);
    let cold = if stat.loaded { 0.0 } else { policy.cold_load_ms };
    (node.queued_tokens + req.est_tokens) as f64 / tps * 1_000.0 + ttft + cold
}

//! Power of two choices with eligibility sampling.

use crate::{NodeId, NodeSnapshot, Policy, Request, Rng, eligible, expected_ms};

/// Random probes before falling back to a full scan.
const PROBES: usize = 16;

/// Choose the node expected to finish `req` first among two sampled eligible candidates.
///
/// Sampling makes the common case O(1) regardless of fleet size; when eligible nodes are too sparse
/// for sampling to find two, a linear scan returns the best eligible node, so an eligible node is
/// never missed.
pub fn pick(candidates: &[NodeSnapshot], req: &Request<'_>, policy: &Policy, rng: &mut Rng) -> Option<NodeId> {
    if let Some(pin) = req.pin {
        return candidates.iter().find(|n| n.id == pin && eligible(n, req, policy).is_some()).map(|n| n.id);
    }
    if candidates.is_empty() {
        return None;
    }
    let score = |n: &NodeSnapshot| eligible(n, req, policy).map(|m| (expected_ms(n, m, req, policy), n.id));
    let mut first: Option<(f64, NodeId)> = None;
    for _ in 0..PROBES {
        let Some(s) = score(&candidates[rng.below(candidates.len())]) else { continue };
        match first {
            None => first = Some(s),
            Some(a) if a.1 != s.1 => return Some(if s.0 < a.0 { s.1 } else { a.1 }),
            Some(_) => {}
        }
    }
    candidates.iter().filter_map(score).min_by(|a, b| a.0.total_cmp(&b.0)).map(|s| s.1)
}

//! Per-node circuit breaker over the last 64 outcomes, kept in one integer.

/// Breaker tuning.
#[derive(Debug, Clone, PartialEq)]
pub struct BreakerPolicy {
    /// Outcomes required before the breaker may open.
    pub min_samples: u32,
    /// Failure share in the window that opens the breaker.
    pub failure_ratio: f64,
    /// Time open before one trial is allowed.
    pub cooldown_ms: u64,
}

impl Default for BreakerPolicy {
    fn default() -> Self {
        Self { min_samples: 10, failure_ratio: 0.5, cooldown_ms: 30_000 }
    }
}

/// Breaker state.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum BreakerState {
    /// Normal operation.
    #[default]
    Closed,
    /// Rejecting work until the cooldown ends.
    Open,
    /// One trial job allowed.
    HalfOpen,
}

/// Sliding-window breaker; bit `1` marks a failure.
#[derive(Debug, Clone, Default)]
pub struct Breaker {
    failures: u64,
    count: u32,
    state: BreakerState,
    opened_at_ms: u64,
}

impl Breaker {
    /// Current state.
    pub fn state(&self) -> BreakerState {
        self.state
    }

    /// Whether a job may be sent now; moves Open to HalfOpen once the cooldown has passed.
    pub fn allows(&mut self, now_ms: u64, p: &BreakerPolicy) -> bool {
        match self.state {
            BreakerState::Closed => true,
            BreakerState::HalfOpen => false,
            BreakerState::Open if now_ms.saturating_sub(self.opened_at_ms) >= p.cooldown_ms => {
                self.state = BreakerState::HalfOpen;
                true
            }
            BreakerState::Open => false,
        }
    }

    /// Record a job outcome.
    pub fn record(&mut self, ok: bool, now_ms: u64, p: &BreakerPolicy) {
        if self.state == BreakerState::HalfOpen {
            if ok {
                *self = Self::default();
            } else {
                self.open(now_ms);
            }
            return;
        }
        self.failures = (self.failures << 1) | u64::from(!ok);
        self.count = (self.count + 1).min(64);
        let window = if self.count == 64 { u64::MAX } else { (1u64 << self.count) - 1 };
        let failed = (self.failures & window).count_ones();
        if self.count >= p.min_samples && f64::from(failed) / f64::from(self.count) >= p.failure_ratio {
            self.open(now_ms);
        }
    }

    fn open(&mut self, now_ms: u64) {
        self.state = BreakerState::Open;
        self.opened_at_ms = now_ms;
    }
}

//! Bounded queue depth per model: refuse early instead of timing out late.

use std::collections::HashMap;

/// The queue for a model is full.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct RetryLater {
    /// Suggested wait before retrying.
    pub retry_after_ms: u64,
}

/// Admission control.
#[derive(Debug, Clone)]
pub struct Admission {
    capacity: u32,
    depth: HashMap<String, u32>,
}

impl Admission {
    /// At most `capacity` queued requests per model.
    pub fn new(capacity: u32) -> Self {
        Self { capacity, depth: HashMap::new() }
    }

    /// Reserve a queue place for `digest`.
    ///
    /// # Errors
    /// [`RetryLater`] carrying `retry_after_ms` when the model's queue is full.
    pub fn try_enter(&mut self, digest: &str, retry_after_ms: u64) -> Result<(), RetryLater> {
        let d = self.depth.entry(digest.to_owned()).or_insert(0);
        if *d >= self.capacity {
            return Err(RetryLater { retry_after_ms });
        }
        *d += 1;
        Ok(())
    }

    /// Release a place; empty entries are removed so the map stays bounded by active models.
    pub fn leave(&mut self, digest: &str) {
        if let Some(d) = self.depth.get_mut(digest) {
            *d = d.saturating_sub(1);
            if *d == 0 {
                self.depth.remove(digest);
            }
        }
    }

    /// Current queue depth for `digest`.
    pub fn depth(&self, digest: &str) -> u32 {
        self.depth.get(digest).copied().unwrap_or(0)
    }
}
