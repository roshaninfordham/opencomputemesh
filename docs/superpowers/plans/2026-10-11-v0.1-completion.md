# OpenComputeMesh v0.1 completion plan

Spec: the "OpenComputeMesh — End-to-End Technical Build Specification" provided by the user in session
(not stored in the repo). Binding constraints are copied below.

## Global Constraints

- No fabricated data: never display fake nodes, traffic, metrics, savings or balances. Unknown values render as "Unavailable", never zero.
- Token counts carry provenance (runtime_reported / estimated / unavailable). Durations from Ollama are nanoseconds, converted to ms; tok/s = eval_count / eval_duration * 1e9.
- Ollama is reached on loopback only; the node agent connects outbound over WS(S); no inbound port on participant machines; models are never auto-downloaded; owners approve which installed models are shared.
- Enrollment tokens are single-use and short-lived, exchanged for a revocable node credential; credentials never in URLs, logs, or shell history.
- Ledger: integer micro-OCC, append-only, idempotent settlement; requester debit equals provider reward; failed/cancelled jobs release the hold and pay nothing.
- Never log raw prompts, outputs, cookies, credentials, join tokens or secrets.
- Browser streaming uses WebSockets (Cloudflare Quick Tunnels don't support SSE).
- Same-origin web app served by the coordinator; mutating cookie-auth routes check Origin.
- README must include the spec's Limitations list (single coordinator/SQLite, URL alone doesn't share compute, Ollama only, no sharding, telemetry gaps, token provenance, OCC non-cash, hosted equivalent hypothetical, single-run benchmark, prompt visibility to node owners, Quick Tunnels temporary).
- Wire protocol version 1 (ocm/protocol.py); the coordinator is unchanged by agent implementations.

## Task 1: Rust node agent (crates/ocm-node)
Single-binary, wire-compatible re-implementation of ocm/agent.py: same CLI flags, same node.json state format (0600), explicit model approval, loopback-only Ollama, enroll/auth, heartbeats, job.start/cancel streaming with final_stats, model.refresh, reconnect with backoff+jitter, fatal close codes 4003/4401. Unit tests for NDJSON decoding against tests/fixtures/ollama_chat_stream.ndjson, loopback check, state round-trip. Verified end to end against a real coordinator + Ollama.

## Task 2: Docs and operator scripts
README (quick start, architecture, metrics definitions, accounting, security model, API list, config table, Limitations), docs/DEMO_RUNBOOK.md, docs/ARCHITECTURE.md, .env.example, LICENSE (Apache-2.0), CONTRIBUTING.md, Makefile, scripts/{dev,build_web,demo_preflight,demo_tunnel}.sh. Every claim matches the code.

## Task 3: Coordinator hardening
Find and fix real correctness/security/resilience defects in ocm/ (enrollment-token atomicity, client WS message validation, cancel of queued jobs, restart recovery idempotency, rate-limiter growth, validation errors not echoing input, list pagination, security headers incl. CSP, no content logging), each with a test that fails without the fix; ledger property test.

## Task 4: Frontend polish
Mobile header/nav, skip link, aria-live run announcements, contrast ≥4.5:1 for muted text, ticking relative times, live browser-observed elapsed time and "chunks received" during runs, disconnected/no-model explanations, per-page document.title. No new dependencies; build passes.
